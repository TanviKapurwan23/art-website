# Tanvi Kapurwan — Art Website

A static portfolio/storefront for original artwork and creative commissions.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and the `images` folder.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available at the GitHub Pages URL.

## Before publishing
- Replace the placeholder email in `index.html` with your real business email.
- Add more original artwork images to `images/` and duplicate/edit the cards in `index.html`.
- Add real prices, dimensions, shipping information and payment/checkout links when ready.
